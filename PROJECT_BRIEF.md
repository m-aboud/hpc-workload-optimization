# Project Brief

## Project name

HPC Workload Optimization & Benchmarking

## GitHub URL

https://github.com/m-aboud/hpc-workload-optimization

## One-line summary

Hands-on HPC benchmarking and workload optimization toolkit for Slurm, MPI, Lustre, IOR, and OSU Micro-Benchmarks.

## Portfolio positioning

This repository demonstrates infrastructure engineering capability across HPC scheduling, scientific workload profiling, parallel file-system tuning, and benchmark-driven operations reporting.

## Keywords

HPC, Slurm, MPI, Lustre, IOR, OSU Micro-Benchmarks, scheduler efficiency, workload optimization, parallel file system, scientific computing, benchmarking, Linux, Bash, Python.

## Interview talking points

- Built a repeatable benchmark workflow for scheduler, MPI, and storage layers.
- Used Slurm accounting exports to detect CPU, memory, walltime, and queue bottlenecks.
- Automated Lustre stripe sweeps to compare large-file I/O layouts.
- Added sample data so the project can be reviewed without access to a real HPC cluster.
- Designed outputs for operational reports, audit evidence, and tuning recommendations.

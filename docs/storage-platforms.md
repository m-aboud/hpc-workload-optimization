# Parallel Storage Operational Awareness

## Lustre
Common HPC parallel filesystem. Operational tasks include MDT/OST awareness, striping, client health, capacity/inode monitoring and IOR-based validation.

## IBM Spectrum Scale / GPFS
Distributed filesystem used in HPC and data-intensive environments. Administrator concepts include NSDs, filesets, quorum, policy-driven placement, health, failure groups and performance monitoring.

## Weka
Scale-out software-defined storage optimized for high-performance workloads. Key operational concepts include client/backend architecture, flash tiering, object integration, throughput/latency monitoring and failure-domain planning.

## VAST Data
Scale-out data platform frequently used for AI/HPC. Operational awareness includes NFS/SMB/object access, disaggregated architecture, performance/capacity telemetry, snapshots/protection and workload isolation.

## How to discuss these honestly
This repository contains **hands-on Lustre lab automation** and **operational architecture awareness** of Spectrum Scale/GPFS, Weka and VAST. Production claims should only be made where independently true.

## Business benefit
Understanding multiple platforms helps translate researcher I/O patterns into the right storage tier, reduces bottleneck misdiagnosis and improves procurement discussions.
